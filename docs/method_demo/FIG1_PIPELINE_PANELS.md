# Fig. 1 pipeline panels (synthetic two-region construction)

Clean, standalone panels for composing a Fig. 1 method-overview schematic.
Generated by `pipeline_figure.py`; raw panels in `pipeline_panels/`, and copied
into `../../figures/out/` with a `fig1_` prefix. A handoff ZIP
is at the repo root: `fig1_pipeline_panels.zip`.

All panels use the **same construction** as the sheaf-vs-kernel demo you liked: a
square grid split into two regions whose fibers have **identical mean and
identical neighbour-distance statistics**, differing only in the *subspace* along
which expression varies (region A in feature dims 0–3, region B in orthogonal
dims 8–11, i.i.d. coefficients everywhere). This is what lets the same figure
both walk through the pipeline and prove the kernel is blind where the sheaf is
not.

Key numbers (printed on each run): mean expression by region +0.004 vs −0.004
(identical); neighbour-distance interface/interior contrast **0.97** (kernel
blind); sheaf disagreement contrast **10.6** (sees the interface); stalk
orientation A 0.98 / B 0.05; recovered-domain **ARI 0.99** vs the true regions.

## Panels

### Pipeline row — fibers → domains

| file | stage | what it shows |
|:--|:--|:--|
| `fig1_00_ground_truth.png` | input regions | the two latent regions actually present in the data (reference) |

| `fig1_02_graph.png` | spatial graph | k-NN graph over grid points (zoomed window so the lattice is legible) |

| `fig1_04_disagreement.png` | difference operator | raw sheaf disagreement across edges = restriction-map misalignment `1 − cos(principal angle)`; a sharp ridge at the interface |

| `fig1_06_domains.png` | domains | boundary-aware domains: remove the boundary ridge, take connected components, backfill — the two regions recovered (ARI 0.99) |

### Kernel-vs-sheaf contrast — why the difference operator

| file | view | verdict |

| `fig1_kernel_mean_expression.png` | kernel: mean intensity | pure noise — **no boundary** |

## Suggested Fig. 1 layout

**Row a–g (pipeline):** `00 → 01 → 02 → 03 → 04 → 05 → 06`, left to right, with a
small arrow between each and the stage name above. This is the method walk-through.

**Row h (why the sheaf, not the kernel):** the four contrast panels side by side —
`kernel_mean_expression`, `kernel_neighbour_distance` (both blind) | `sheaf_stalk_orientation`,
`sheaf_principal_angle_hist` (both see it). A vertical divider between the two
kernel panels and the two sheaf panels drives the point home: *same mean, same
neighbour distances, different subspaces — only the sheaf difference operator
distinguishes the regions.*

The panels are transparent-background PNGs at 220 dpi, so they drop cleanly onto
a white or light figure canvas in Illustrator/Inkscape. Add panel letters and
stage labels in the layout tool.
